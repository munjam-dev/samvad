# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

Platform: native Android (Kotlin, Jetpack Compose, Material 3). Read "px" in the skills as dp, and font sizes as sp.

## Aesthetic reference

- **Standard:** Apple Native
- **Notes:** Apple Native restraint (generous spacing, unified radii, fluid but short motion, calm neutral surfaces) applied on top of Samvad's existing **Botanical Modernism** tokens: ivory `background`, forest-green `primary`, sage and champagne containers, Inter for Latin with system Noto for Indic scripts. Tokens, type scale, shapes and motion are defined in `docs/superpowers/specs/2026-10-13-android-design-system-client.md` and implemented in `core/design/` and `ui/theme/`. Screens use only `MaterialTheme` and `SamvadTheme` tokens, with no hex values outside the design-system code. Elevation is tonal first; shadows only on the FAB, sheets, dialogs and call controls. Motion: M3 emphasized easing, 150–300 ms, press scale ≤ 0.97, and all non-essential animation off when the system animation scale is 0. Real conversations and user media carry the visual richness, so there are no promotional banners.

## Banned anti-aesthetics

- Glassmorphism, blur or translucent frosted layers behind content
- Floating pastel pill badges for ordinary metadata
- Decorative gradients and neon or glowing borders (gradients only on splash/onboarding, the call background and the profile header)
- Multi-colour or rainbow gradients on buttons and CTAs
- Cartoon empty-state illustrations (people waving, high-fiving)
- Nested scrolling regions, and icon bloat inside text fields
- Emoji as UI icons (emoji appear only in user content)
- Endless shimmer loops (skeletons show only during the load window)

## Accessibility target

- **Level:** WCAG 2.1 AAA
- **Contrast:** ≥ 7:1 for normal text, ≥ 4.5:1 for large text (≥ 24 sp, or ≥ 18.67 sp bold), ≥ 3:1 for UI component boundaries and focus indicators. State never relies on colour alone or on dividers. **Open token work:** several light-theme pairs in the design spec are AA but not AAA and must be darkened before new UI ships against this profile: white on `primary` buttons (5.26), `onSurfaceVariant` secondary text (5.45), `primary` links/icons on background (4.83), error (5.97) and warning (4.79) text, outgoing-bubble meta (6.0) and `onTertiaryContainer` (6.96). The design-system contrast unit test must check the AAA thresholds.
- **Touch / focus:** Every interactive element has a ≥ 48 × 48 dp touch target. Keyboard and switch-access focus shows a prominent, high-contrast focus indicator. Every icon-only control has a string-resource content description. Text is in sp and checked at 200% font scale without clipping or overlap. Screens are checked with TalkBack.

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Clear, kind and calm, like a thoughtful friend; never cute or salesy. Say what happened and what to do next in plain words ("We'll text you a 6-digit code to confirm it's you."). Address the user as "you". Errors explain the fix without blame. No exclamation marks in errors, and no fear-based wording in security and privacy copy. Write short sentences that translate cleanly into Hindi and other Indian languages: avoid idioms, puns and English-only wordplay. All strings live in `strings.xml`, with plurals for counts.

## Icon library

- **Library:** Material Icons (Outlined)
- **Package / path:** `androidx.compose.material:material-icons-extended` (`Icons.Outlined.*`, and `Icons.AutoMirrored.Outlined.*` for directional icons); brand marks live in `android-native/app/src/main/res/drawable/` (`ic_samvad_mark`, `ic_notification`, launcher layers)
- **Notes:** Outlined style only. Use filled variants only for a selected or active state of the same glyph. 24 dp glyph (20 dp inline) inside a ≥ 48 dp target; use AutoMirrored for anything directional so RTL stays correct. The design spec says "Material Symbols Rounded", which doesn't match the code. This profile records the set actually in use, and the spec should be corrected to match.

## Agent rules

1. Read this profile before creating or editing any UI, theme, or microcopy.
2. Prefer skills by task: new screen → `page-patterns` (name the pattern before writing the composable); layout / chrome → `viewports`; forms → `forms`; dialogs, sheets and menus → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or the project drawables). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
